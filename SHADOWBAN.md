# Теневой бан (локальный)

Патч к Telegram-Android (GPLv2): сообщения выбранных пользователей скрываются **только на вашем устройстве**.
Сервер Telegram и сам пользователь ничего не узнают.

## Как пользоваться
Долгое нажатие на чужое сообщение в чате → «Теневой бан» (повторно → «Снять теневой бан»).

## Что скрывается
- история чата при открытии
- новые входящие сообщения
- уведомления

Список хранится локально в SharedPreferences `shadow_ban`.

## Сборка на GitHub
1. Сделайте форк/залейте этот код в свой репозиторий.
2. Получите свои `api_id` и `api_hash` на https://my.telegram.org (требование Telegram для сторонних клиентов).
3. Settings → Secrets and variables → Actions: добавьте `TG_API_ID` и `TG_API_HASH`.
4. Actions → Build APK → Run workflow. APK появится в артефактах.

## Лицензия
Код Telegram-Android распространяется под GPLv2: форк должен оставаться открытым.
Не используйте логотип и название Telegram как свои, а также соблюдайте API Terms of Service.

## Ограничения
- В файле `google-services.json` лежат ключи официального приложения, так что push через Firebase в форке работать не будет. Уведомления будут приходить через фоновое соединение. Для push нужен свой Firebase-проект.
- Сборка не проверялась на устройстве, только патч применён к исходникам.
